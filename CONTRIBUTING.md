# 🤝 Guía de contribución

¡Gracias por tu interés en contribuir al proyecto Tienda TECSUP!

## 🐛 Reportar un error

Si encuentras un error:

1. Accede a la sección Issues del repositorio.
2. Describe claramente el problema.
3. Indica los pasos para reproducirlo.
4. Adjunta capturas de pantalla si es necesario.

## 💡 Proponer una mejora

Para proponer una nueva funcionalidad:

1. Explica la mejora que deseas implementar.
2. Describe por qué sería útil.
3. Espera la revisión de la propuesta antes de realizar cambios importantes.

## 🔀 Enviar un Pull Request

Antes de enviar un Pull Request, verifica lo siguiente:

- [ ] El código funciona correctamente.
- [ ] Los cambios mantienen la estructura del proyecto.
- [ ] No se han agregado archivos innecesarios.
- [ ] Se ha probado la funcionalidad modificada.
- [ ] El mensaje del commit describe claramente los cambios.
- [ ] Se ha actualizado el README.md si corresponde.

## 📋 Estándares de desarrollo

- Utilizar HTML semántico.
- Mantener los estilos en `estilos.css`.
- Mantener la lógica JavaScript en `script.js`.
- Escribir código legible y organizado.

¡Gracias por colaborar!
